# Planned Features

Các tài liệu trong thư mục này mô tả feature đã được phân tích và lên kế hoạch nhưng
**chưa phải runtime contract hiện tại**. Chỉ chuyển một tài liệu sang `docs/features/`
khi source, test và device verification của feature tương ứng đã hoàn tất.

- [Battery Status Capsule](battery-status-capsule/README.md): thanh trạng thái trang trí
  chạy nổi với theme, pin, thời gian, emoji và các chỉ báo thiết bị.
